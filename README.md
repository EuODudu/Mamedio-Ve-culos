# Mamedio Veículos - Landing Page

## Sobre o Projeto

Landing page profissional e focada em conversão para a Mamedio Veículos, especializada em veículos selecionados com procedência garantida.

## Como executar o projeto

### Requisitos

- Node.js & npm instalados - [instalar com nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Passos para execução

```sh
# Passo 1: Navegar até o diretório do projeto
cd mamedio-veiculos

# Passo 2: Instalar as dependências necessárias
npm install

# Passo 3: Iniciar o servidor de desenvolvimento
npm run dev
```

O servidor estará disponível em `http://localhost:8080`

## Tecnologias utilizadas

Este projeto foi construído com:

- **Vite** - Build tool e dev server
- **TypeScript** - Tipagem estática
- **React** - Biblioteca JavaScript para interfaces
- **shadcn-ui** - Componentes UI
- **Tailwind CSS** - Framework CSS utilitário

## Scripts disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Cria build de produção
- `npm run preview` - Preview do build de produção
- `npm run lint` - Executa o linter
